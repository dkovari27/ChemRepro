HOW TO CHECK FEEDBACK SUBMISSIONS
==================================

You have two options depending on whether you want to check quickly
online or read a nicely formatted page locally.


OPTION 1 — Railway dashboard (online, no setup needed)
-------------------------------------------------------
1. Go to railway.app and open the ChemRepro project
2. Switch to the "Database" environment
3. Click the PostgreSQL service
4. Click the "Data" tab in the top menu
5. Select the "feedback" table from the left panel
6. All submissions appear as rows with: preference, comment, orcid_id, created_at


OPTION 2 — Admin page (local dev server, formatted view)
---------------------------------------------------------
1. Start the local server:
      cd C:\Users\danik\Desktop\Python\chemrepro
      uvicorn app.main:app --reload

2. Open your browser and go to:
      http://localhost:8000/admin/feedback

3. You will see a summary with counts per preference option
   and all individual submissions listed below.

NOTE: The admin page is blocked on the deployed (Railway) site
on purpose — it only works on localhost.


WHAT THE FEEDBACK FIELDS MEAN
------------------------------
preference  — which scoring mode the user preferred:
              standard / classic / both / unsure
comment     — free-text comment (optional, up to 2000 chars)
orcid_id    — "local:UUID" for guest users, ORCID iD for signed-in users
              (NULL if submitted without logging in)
created_at  — timestamp of submission (UTC)


EMAIL NOTIFICATIONS
-------------------
Every submission also triggers an email to chemrepro@gmail.com
from chemrepro@gmail.com — subject: [ChemRepro] New feedback – <preference>
If no email arrives, the feedback is still safely saved in the database.
Check Railway logs (Test env → web service → Logs) for SMTP errors.
