## Scoring Logic

### Standard mode
- User picks one **outcome**: no_repro(1) / no_extension(2) / reproduced(3) / repro_extension_failed(4) / extended(5)
- Score is the outcome's numeric value
- Community score = average of all Standard ratings for a paper
- Score card shows bar breakdown by outcome category

### Classic mode
- User gives two independent star ratings (1–5):
  - **Reproducibility** (amber) — 1=Failed completely, 3=Partially reproduced, 5=Reproduced exactly
  - **Extension scope** (blue) — 1=Minor/same scaffold, 3=Medium/new scaffold, 5=Major/new function
- Either or both can be submitted (extension-only reviews allowed)
- Two separate averages shown on paper card and page

## Known Issues / Bugs Outstanding
- **Abstract gap:** CrossRef has no abstract for some ACS papers (e.g. `10.1021/acs.joc.4c02690`). Currently silently hidden. Fix: Europe PMC fallback in `crossref.py → fetch_paper_metadata()`.
- **API `/api/v1/papers` scores not mode-filtered:** The API aggregates all ratings regardless of `scoring_mode` — mixing Standard and Classic in one average. Low priority until API is publicly promoted.
- **No 404 HTML page:** FastAPI returns raw JSON `{"detail": "Not found"}` for 404s. Should have a proper HTML error page.
- **ORCID OAuth not tested end-to-end in sandbox:** sandbox.orcid.org credentials are placeholders (`APP-XXXXXXXXXXXX`). Guest login is the only tested auth path.
