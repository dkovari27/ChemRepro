## Features — Working

- Paper lookup by DOI via CrossRef; abstract fallback via Europe PMC
- DOI normalisation: bare DOI, doi: prefix, full publisher URLs (ACS, Wiley, Springer, PubMed)
- Standard scoring: outcome-based (1-5 mapping), one submission per paper per user
- Classic scoring: dual star ratings (repro + extension), separate submission
- Guest login with localStorage reconnect
- ORCID login (sandbox; production blocked pending HTTPS registration)
- Likes on reviews (AJAX)
- Comment threading 1 level deep with likes
- Markdown in comments (live preview, bleach-sanitised)
- Social share popup (WhatsApp, Email, LinkedIn, Copy)
- Review edit and delete (own reviews only)
- Pagination + filter + sort on paper review list (newest/oldest/highest/lowest/most_liked)
- Paper subscriptions (follow/unfollow, in-app notification on new review/comment)
- User follow system (follow/unfollow from reviewer name dropdown)
- Private in-mail messaging (inbox, thread view, reply, new thread from reviewer dropdown)
- In-app notifications (bell icon, unread count badge, mark-read on visit)
- Author email notification on review — `AUTHOR_NOTIFY_ENABLED=False` (disabled pending test); CrossRef → Europe PMC → PubMed chain; HMAC opt-out
- Content moderation: server-side blocklist in papers.py and messages.py
- Feedback form + name suggestion voting (beta)
- Profile settings: nickname, career stage, notification email
- Subscriptions page: manage followed papers and users
- My Reviews page
- Custom 404/403/422/500 error pages
- API v1 (public, read-only)
- About, Privacy pages
- v2 design: blue brand (#1e40af), review card 3-column header, reviewer name dropdowns

## Features — Not Working / Blocked

| Feature | Reason | Fix |
|---|---|---|
| ORCID production login | Redirect URI must be HTTPS; not registered | Register on orcid.org when production domain is ready |
| Author email notifications | `AUTHOR_NOTIFY_ENABLED=False` | Enable via Railway .env after testing (B11) |
| Email alerts for paper subscribers | `notification_email` field saved but not wired to SMTP sender | Needs wiring (F6) |

## How to Deploy
1. Test locally: `uvicorn app.main:app --reload`
2. Commit: `git add <files> && git commit -m "..."`
3. Push (explicit user instruction required): `git push origin impeccable`
4. Railway auto-redeploys within ~90 seconds.
5. If DATABASE_URL resets in Railway, re-paste the PostgreSQL public URL manually.

## How to Check Feedback
Connect to Railway Data tab → `feedback` table, or run locally and visit `/admin/feedback`.
