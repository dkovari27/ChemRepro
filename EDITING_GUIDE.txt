ChemRepro: Where to Edit Labels and Tutorial Text
====================================================

1. ND STAR LABELS (the 5-point rating scale)
---------------------------------------------
File: app/routers/papers.py
Dict: ND_STAR_LABELS (around line 82)

    ND_STAR_LABELS = {
        1: "Did not work",
        2: "Reproduced with deviation",
        3: "Reproduced as published",
        4: "Minor extension (no new functional group)",
        5: "Major extension (new functional group)",
    }

Editing this dict updates ALL pages automatically:
  - ND homepage (/)
  - ND paper page (/paper/...)
  - Edit rating page
  - Demo paper page (/paper/demo)
  - Demo homepage tooltip (/demo)

No double-maintenance needed anywhere for the demo pages.


2. ND STAR COLORS
-----------------
File: app/routers/papers.py
Dict: ND_STAR_COLORS (just below ND_STAR_LABELS)

Each key maps to [bar-class, text-class] Tailwind CSS strings.
Change these if you want to update the color scheme for a star level.


3. ND FAILURE CONTEXT LABELS (shown when star = 1)
---------------------------------------------------
File: app/routers/papers.py
Dict: ND_FAILURE_CONTEXT_LABELS

    ND_FAILURE_CONTEXT_LABELS = {
        "original_tested": "Tested original procedure",
        "extension_only":  "Extension only ...",
    }


4. PRODUCT TOUR STEP TEXT
--------------------------
File: app/static/js/tour.js
Array: STEPS (starts at line 7)

Each step object has:
  - title: short headline shown in the tooltip
  - body: longer HTML description (bold with <strong>)
  - stepNum: "Step N of 7" label

The tour is only shown locally (when ORCID_ENV=sandbox). It is
automatically hidden in production (Railway) without any code change.


5. TOUR STEP LABELS vs. ND_STAR_LABELS
----------------------------------------
tour.js is the ONE place that still has star label text hardcoded
(in step 3 body and step 4 body). If you rename a label in
ND_STAR_LABELS, also update the matching text in tour.js manually.


6. THINGS THAT ARE FULLY AUTOMATIC (no action needed)
------------------------------------------------------
- All real ND pages pick up label changes from papers.py.
- demo.html and demo_index.html now pull labels via Jinja2 -- no
  separate editing needed there.
- "Take a tour" button is already hidden in production (no code
  change required before pushing to Railway / GitHub).


7. URL STRUCTURE
------------------
Homepage: / (also /nd/ and /nd as legacy aliases)
Active paper pages: /paper/{doi}  (the main ChemRepro rating view)
Classic archive: /classic/paper/{doi}
Standard archive: /design-archive/standard/paper/{doi}


8. HOW TO ACCESS THE OLD STANDARD AND CLASSIC VIEWS
------------------------------------------------------
Both older views are still fully functional but not linked from the
main navigation. To reach them, type the URL directly in the browser:

  Standard view (older 5-outcome scoring):
    http://localhost:8000/design-archive/standard/paper/{doi}
    Example: http://localhost:8000/design-archive/standard/paper/10.1021/jacs.2c00001

  Classic view (reproducibility stars + outcome):
    http://localhost:8000/classic/paper/{doi}
    Example: http://localhost:8000/classic/paper/10.1021/jacs.2c00001

  Classic homepage (shows classic-mode rated papers):
    http://localhost:8000/classic/

On Railway (production), replace localhost:8000 with chemrepro.com.

The old Standard view code lives in:
  - Route handlers: app/routers/papers.py  (search "design-archive/standard")
  - Template:       app/templates/paper.html  (or paper_v1.html for the older layout)

The Classic view code lives in:
  - Route handlers: app/routers/papers.py  (search "/classic/paper/")
  - Templates:      app/templates/paper_classic.html  and  paper_classic_v1.html
